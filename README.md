### 🔴 Forge CLI

**A practical project scaffolding tool built with Go.**

Generate new projects from predefined technology stacks through a command-line workflow.

- Cobra for commands and flags.
- Bubble Tea for interactive terminal experiences.
- Templates and automated file generation.
- A maintainable structure that can grow over time.

`STATUS: PLANNED / NEXT DEVELOPMENT STAGE`

### 🔴 Steam Judge

**A desktop application for group game voting.**

Users sign in with Steam, join rooms, vote on games, and launch the winning game.

- Go backend and API.
- Steam OpenID authentication.
- Sessions, rooms, and voting.
- Integration between the backend and desktop application.

`STATUS: IN PROGRESS`

### 🔴 Wordle in Go

A small game for practicing Go fundamentals through implementation.

- Strings, slices, and runes.
- Random word selection.
- Guess validation and game logic.

`STATUS: PLANNED`
